# React Student & Movie Watchlist

Навчальний React-застосунок на Vite: генератор випадкових фактів, каталог студентів, лічильник відвідувань і список фільмів із збереженням у localStorage.

## Запуск

```bash
npm install
npm run dev
```

## Функції

- Завантаження випадкового факту через `fetch` та `async/await`.
- Каталог студентів із фільтром за курсом і показом/приховуванням карток.
- Лічильник відвідувань на `useState` зі скиданням.
- Movie Watchlist: додавання фільмів, позначення переглянутих і збереження в `localStorage`.
